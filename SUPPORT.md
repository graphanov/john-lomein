# Support

John Lomein is alpha software with best-effort community support.

## In scope

Use the public issue tracker for reproducible defects in the generic product, documentation errors, portability problems, and bounded feature proposals.

A useful report includes:

- product version or commit;
- operating system and architecture;
- the exact command and public-safe error;
- expected and observed behavior;
- a minimal reproduction;
- confirmation that secrets and private paths were removed.

## Out of scope

Public support does not cover:

- credentials, account recovery, or private repository access;
- inspecting private memory, database dumps, gateway IDs, or raw logs;
- operating a public Discord community on someone else's behalf;
- merging, releasing, publishing, or changing repository settings;
- guarantees for arbitrary model providers, third-party plugins, or modified runtimes;
- emergency response or uptime commitments.

For security issues, follow [SECURITY.md](SECURITY.md). For contribution rules, follow [CONTRIBUTING.md](CONTRIBUTING.md).
