# Alpha notice

John Lomein is experimental software.

The current release is suitable for development, personal use, and an owner-activated invite-only pilot. It is not yet proven for unrestricted public traffic, unattended merge/release authority, or high-volume memory ingestion.

Example manifests remain conservative: observer posture, public gateways off, repository mutation off, schedulers off, merge/publish off, and owner gates preserved. A specific owner may deliberately activate supported capabilities for an alpha release while accepting the documented limitations and post-release remediation burden.

Participant deletion and destructive retention are supported only through the dedicated public Honcho service, exact-ID plans, verified public-only backups, tombstones, and startup replay gates. Protected release automation, npm publication, and advisory agent collaboration remain unavailable until their documented implementation or credential prerequisites are satisfied. Enabling other capabilities does not silently bypass those boundaries.

Protected persona qualification also remains unavailable on a macOS host whose filesystem cannot atomically rename a sealed capture directory. CI skips only the affected live capture/adoption cases on such a host; portable contract and tamper tests continue to run.

Interfaces and state formats may change before `1.0.0`. Keep backups and read migration notes.
